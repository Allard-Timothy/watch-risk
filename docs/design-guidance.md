# Design guidance

## Reference asset

Use this image as the visual guidance reference:

```text
assets/watchdesk-risk-report-dashboard.png
```

This image was created as an earlier risk-analysis report dashboard direction.

It should guide:

- layout density
- report-card feel
- professional tone
- visual hierarchy
- calm technical aesthetic

It is not a pixel-perfect design contract.

## Visual goals

The product should feel:

- confident
- intelligent
- trustworthy
- sharp
- calm
- mechanical
- precise

Avoid:

- AI purple gradient branding
- overused blue SaaS look
- crypto dashboard feel
- playful consumer app styling
- loud neon colors
- vague magic-AI visuals
- brand marks that resemble Rolex or another watch company

## Suggested design language

Use a restrained palette:

- warm off-white background
- charcoal text
- muted steel gray borders
- subtle beige/tan accent
- dark green or graphite for confidence
- amber for caution
- red only for serious risk

Typography should be clean and practical.

The UI should feel closer to:

- a professional inspection report
- a mechanical instrument panel
- a quiet financial risk dashboard

Not:

- a chatbot
- a social app
- an AI demo
- a watch marketplace

## Layout guidance

The report page should prioritize:

1. overall risk
2. confidence limitation
3. missing evidence
4. visible concerns
5. seller questions
6. recommended next step

Use cards, sections, and clear labels.

Do not bury the disclaimer. It should be visible but not visually dominant.

## Mobile-first guidance

Most users will upload photos from their phones.

Optimize for:

- one-column mobile layout
- large touch targets
- clear upload states
- obvious next action
- concise section headings
- report that can be screenshotted

## Report UI sections

Suggested sections:

```text
Overall assessment
Evidence quality
Missing photos
Visible concerns
Reference consistency
Seller-risk signals
Questions to ask
Recommended next step
Disclaimer
```

## Tone

The interface should be direct and practical.

Use language like:

- Review incomplete
- Request more evidence
- Visible concern
- Proceed with caution
- Independent inspection recommended
- Low visible risk

Do not use language like:

- AI certified
- verified genuine
- instant authentication
- official-grade scan
